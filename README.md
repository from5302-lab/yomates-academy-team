# yomates-academy-team

학원 원장님 요메이트(Yomates)에 학원 AI 팀 12명을 한 번에 들이는 스킬이에요. 충쌤(에듀-온) 학원 자동화 컨설팅에서 세팅해 드리는 팀이에요.

## 설치

요메이트 팀원에게 이렇게 보내요.
> https://github.com/from5302-lab/yomates-academy-team 의 SKILL.md 읽고 '학원-AI-팀-세팅' 스킬로 저장해 줘. 그다음 바로 실행해 줘.

학원 이름, 과목, 대상 학년, 들일 팀원을 물어본 뒤 12명을 들이고 '우리 학원' 그룹 채팅을 만들어요.

## 팀 12명

| 팀원 | 맡은 일 |
|---|---|
| 상담실장 | 신규 문의 첫 답장과 상담 예약 |
| 데스크 | 결석 안내와 보강 잡기 |
| 수납 | 원비 청구와 미납 안내 |
| 학습매니저 | 학생별 월말 리포트 완성 |
| 강사코디 | 강사 일지 취합과 공지 |
| 수업조교 | 녹화 정리와 업로드 |
| 마케터 | 스레드·인스타 글과 후기 정리 |
| 채점조교 | 과제·시험 채점과 오답 정리 |
| 출제 | 단어 시험지와 내신 대비 문제지 |
| 입시정보 | 학교 일정과 입시 공지 정리 |
| 블로그 | 블로그 글 쓰고 올리기 |
| 매니저 | 일 나누고 하루 보고 |

## 지키는 것

- 학부모·학생에게 나가는 글은 원장님이 "바로 보내도 돼"라고 정한 종류만 바로 보내요. 처음에는 보내기 전에 한 번 보여 드려요.
- 비밀번호·키·카드 번호는 채팅으로 받지 않아요. 로그인은 원장님이 직접 해요.
- 원비, 시간표, 점수처럼 모르는 숫자는 지어내지 않고 처음 한 번 물어요.
