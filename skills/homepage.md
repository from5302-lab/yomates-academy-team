# 학원 홈페이지 관리

## 처음 한 번
1. 홈페이지가 있는지 묻는다. 없으면 'firebase-세팅' 스킬로 만든다. 원장님은 구글 로그인만, 도구 설치·프로젝트·첫 배포는 내가 한다.
2. 작업 폴더는 `~/학원홈페이지` 하나로 정하고 장부 '기본'에 주소와 폴더를 적는다.
3. 첫 화면 구성(한 페이지로 시작): 학원 이름·한 줄 소개 → 반·시간표 → 원비(교육청에 게시한 금액 그대로) → 선생님 → 후기(동의 받은 것, 이름 가림) → 오시는 길·주차 → 상담 신청.
4. 상담 신청 칸: 이름, 학년, 연락처, 원하는 시간. 'firebase-세팅'의 Firestore에 저장하고, 들어오면 @상담실장 에게 넘긴다. 개인정보 수집 동의 문장(목적: 상담 연락, 보관: 상담 후 1년)을 칸 바로 위에 둔다.

## 고칠 때
- 값(시간표, 원비, 주소, 전화)은 '학원-정보-장부'에서만 가져온다. 장부와 다르면 고치기 전에 원장님께 묻는다.
- 원비는 교육청에 신고·게시한 교습비와 같은 금액으로만 쓴다.
- 공지(휴원, 시험 기간 일정)는 위쪽 띠로 넣고 끝나는 날짜를 정해 그날 내린다.
- 사진은 원장님이 준 것만, 학생 얼굴은 동의 받은 것만. "1등", "성적 보장" 같은 말은 쓰지 않는다.

## 배포
1. '학원-화면-uiux-점검'을 끝까지 한다. 실패한 항목이 있으면 배포하지 않는다.
2. `firebase.json`의 hosting `ignore`에 `.git`, `**/.*`, `node_modules`, 작업 메모 폴더가 들어 있는지 본다. 숨김 폴더가 공개 사이트에 올라가면 누구나 볼 수 있다.
3. css·js를 고쳤으면 html의 `?v=` 숫자를 올린다(휴대폰이 예전 파일을 붙잡지 않게).
4. `firebase deploy --only hosting --project <아이디>`.
5. 실제 주소를 `?t=시각`을 붙여 열어 바뀐 글자가 보이는지 확인한다.

## 판 정리
Firebase는 배포한 판을 다 보관해서 저장 공간이 찬다. 처음 한 번 콘솔 Hosting → 출시 기록 설정에서 보관 판 수를 20으로 정한다(내가 화면 조작, 로그인은 원장님).
