# 학원 문자 보내기 (솔라피)

문자는 솔라피로 보낸다. 명령은 'solapi-연결' 스킬의 CLI `~/yomates-solapi/solapi.mjs` 하나다. 윈도우는 `"$HOME\yomates-solapi\solapi.mjs"`.

## 0. 연결 확인 (보낼 때마다 먼저)
```
node ~/yomates-solapi/solapi.mjs status
```
- `connected: false`이거나 파일이 없으면, 보내기 전에 'solapi-연결' 스킬의 '처음 한 번'을 처음부터 한다.
  - 원장님이 할 일은 솔라피 로그인, 발신번호 인증번호 입력, 충전 결제뿐이다. API 키 만들기와 저장, 발신번호 등록 화면 조작, 시험 발송은 내가 한다.
  - 키와 시크릿은 원장님께 채팅으로 달라고 하지 않는다. 화면의 복사 버튼과 CLI의 `--from-clipboard`로만 저장한다.
- `balance`가 보낼 양보다 적으면 원장님께 충전을 부탁한다(충전 화면까지는 내가 연다).
- `senders`가 비어 있으면 발신번호 등록부터 한다.

## 1. 받는 사람
- 명단(학원-정보-장부의 '명단' 위치)에서 뽑는다. 번호는 숫자만 남긴다.
- 한 명이면 `send`, 두 명 이상이면 `bulk`를 쓴다.
- `bulk` 목록은 작업 폴더에 CSV로 만든다. 한 줄에 `번호,내용`. 내용에 쉼표가 있으면 큰따옴표로 감싸고, 줄바꿈은 `\n`.
  ```
  번호,내용
  01012345678,"[○○학원] 민수 학생이 오늘 6시 수업에 아직 오지 않았어요."
  ```
- 학생마다 이름이 다른 문자도 한 줄씩 내용만 바꿔 같은 파일에 넣는다.

## 2. 바로 보내도 되는 글인지
장부의 '바로 보내도 되는 글'에 이 종류가 있는지 본다.
- 있으면 미리보기를 확인한 뒤 바로 보낸다.
- 없으면 원장님께 미리보기(받는 사람 수, 문구 한두 개, 보낼 시각)를 보여 주고 "보내도 될까요?"를 묻는다. "앞으로 이 종류는 바로 보내"라고 하면 장부에 적는다.

## 3. 문구 규칙
- 첫머리에 "[○○학원]".
- 학생은 "○○ 학생", 보호자는 "학부모님".
- 90바이트(한글 약 45자)를 넘으면 장문(LMS)이 되고 요금이 오른다. 줄일 수 있으면 줄인다.
- 금액·날짜는 장부 값만 쓴다.
- 홍보 문자(수강 모집, 이벤트)는 첫머리에 "(광고)", 끝에 수신 거부 방법을 넣는다. 밤 9시~아침 8시에는 보내지 않는다.
- 안내 문자도 밤 9시~아침 8시에는 급한 일(당일 결석, 휴원)이 아니면 아침 9시 넘어 보낸다.

## 4. 보내기
한 명:
```
node ~/yomates-solapi/solapi.mjs send --to 01012345678 "내용"          # 미리보기
node ~/yomates-solapi/solapi.mjs send --to 01012345678 "내용" --yes    # 실제 발송
```
여러 명:
```
node ~/yomates-solapi/solapi.mjs bulk --file 목록.csv          # 미리보기: 보낼 수, SMS/LMS 수, 뺀 번호
node ~/yomates-solapi/solapi.mjs bulk --file 목록.csv --yes    # 실제 발송
```
- 미리보기의 `skippedBad`(휴대폰 번호가 아님)·`skippedDuplicate`(겹친 번호)는 원장님께 알린다.
- 보낸 뒤 목록 CSV는 바로 지운다. 학생 연락처가 들어 있다.

## 5. 기록과 보고
- `academy/문자기록/YYYY-MM.md`에 한 줄: 날짜 시각 · 종류 · 보낸 수 · 실패 수 · 뺀 번호 수.
- 실패한 번호는 원장님께 따로 알린다. `history`로 그날 결과를 다시 볼 수 있다.
- 보고는 수량으로: "결석 안내 3건 발송(실패 0)".
