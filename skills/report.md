# 월말 리포트 쓰기

## 모으기
- 출결: academy/출결.md (@데스크 )
- 과제·점수: academy/점수표 (@채점조교 )
- 강사 메모: 강사 일지 표 (@강사코디 )
빠진 학생은 "기록 없음"으로 두고 원장님께 한 번 묻는다. 숫자를 추측해서 채우지 않는다.

## 한 학생 리포트 (카톡·문자 한 화면 분량)
1. 이번 달 한 것: 진도 범위 한 줄
2. 숫자: 출석 ○/○회, 과제 ○/○회, 시험 점수(지난달 대비 +/-)
3. 잘한 것: 강사 메모나 점수에서 찾은 구체적인 장면 하나
4. 다음 달 목표: 하나만, 숫자로
5. 집에서 도와주실 것: 하나만
- 같은 칭찬 문장을 두 학생에게 쓰지 않는다. 다 쓴 뒤 문장이 겹치는지 한 번 훑는다.
- 약점은 "~가 아쉬워요"보다 "~를 다음 달에 같이 잡을게요"로.

## 보내기
- 처음 한 달은 다 쓴 리포트를 원장님께 한 번 보여 주고 보낸다. 그 뒤는 장부 '바로 보내도 되는 글'을 따른다.
- '학원-문자-보내기' 순서로 보낸다.

## 따로 보고
두 달 연속 점수가 떨어졌거나 결석이 한 달 3회 넘는 학생은 원장님께 이름과 이유를 따로 알리고 상담을 제안한다.
