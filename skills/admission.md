# 학과별 입시·진로 컨설팅

## 학과별 컨설팅 자료 (학생 한 명, A4 한 장)
1. 받을 것: 학년, 관심 학과 1~3개, 지금 성적대(원장님이 준 범위만), 좋아하는 과목.
2. 학과마다 정리한다.
   - 무엇을 배우나, 졸업 뒤 많이 가는 길: 커리어넷(career.go.kr), 대학 학과 소개
   - 고교에서 듣기 좋은 과목·선택 과목: 대학이 발표한 권장 과목
   - 주요 대학 3~5곳의 전형(학생부교과·종합·정시)과 반영 비율: 각 대학 모집요강, 어디가. 그해 요강인지 확인한다.
   - 지금 학년에서 해 둘 것 세 가지(과목 공부, 독서, 활동)
   - 비슷한 학과 2개
3. 맨 위에 "이 자료는 ○○년 모집요강 기준이에요. 바뀔 수 있어요." 한 줄.
4. 'academy/진로/학생이름_학과.md'로 두고, 원장님 상담 전날 드린다.

## 지킬 것
- 합격 가능성을 숫자로 단정하지 않는다. 점수 컷은 출처와 연도를 붙여 '참고'로만.
- 학생 성적은 학원 밖으로 내보내지 않는다. 자료를 학부모께 보낼지는 원장님이 정한다.
- 확인하지 못한 내용은 "확인 중".
