# 하루 보고와 일 나누기

## 누구 일인지
| 이런 말 | 맡는 팀원 |
|---|---|
| 문의, 상담, 레벨테스트 | @상담실장 |
| 결석, 지각, 보강, 휴원 공지 | @데스크 |
| 원비, 미납, 영수증 | @수납 |
| 월말 리포트, 학부모 피드백 | @학습매니저 |
| 강사 일지, 강사 공지, 진도 | @강사코디 |
| 수업 녹화, 영상 링크 | @수업조교 |
| 스레드, 인스타, 후기 | @마케터 |
| 채점, 오답 | @채점조교 |
| 시험지, 문제지 | @출제 |
| 학교 시험 일정·범위 | @출제 |
| 학과별 입시·진로 상담 자료 | @입시정보 |
| 홈페이지, 시간표·원비 게시, 상담 신청 칸 | @홈페이지 |
여러 명 일이면 순서를 정해 넘긴다(예: 채점 → 리포트 → 발송). 누구 일인지 애매하면 원장님께 한 번 묻는다.

## 넘기는 법
"@이름 할 일 · 기한 · 끝나면 나에게 수량으로 보고" 한 줄. 무거운 일(영상 편집, 브라우저)은 2~3명씩 나눠 순서대로 맡긴다.

## 챙기기
'academy/할일.md': 받은 날 · 일 · 맡은 팀원 · 기한 · 상태. 기한이 지난 일은 그 팀원에게 한 번 묻고, 막힌 이유를 원장님께 알린다.

## 하루 보고 (매일 밤 10시, 다섯 줄 안)
1. 오늘 팀이 끝낸 일과 수량
2. 원장님 승인을 기다리는 것
3. 막힌 것과 이유
4. 내일 할 것
예: "오늘 끝낸 일: 문자 14건 발송, 리포트 12명 완성, 홈페이지 시간표 반영. 승인 대기 2건(미납 2차 안내). 내일: 단어 시험 채점."

## 주간 보고 (금요일)
출석률, 신규 문의·등록 수, 미납 건수, 리포트 발송 수, SNS 글 수와 조회수, 홈페이지 상담 신청 수를 한 표로.

## 루틴 제안
같은 일을 세 번 받으면 "매주 ○요일 ○시에 알아서 돌게 할까요?"라고 한 번 묻는다. 원장님이 좋다고 할 때만 루틴을 만든다.
